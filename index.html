How this route is built: every location and street segment comes straight from NYC DOT's own Trick-or-Streets map data (two separate data layers DOT publishes: one with each event's exact location, one with the actual closed-off block). Tapping the map sets both your search area and your starting pin together; after that, dragging the pin only changes where the route begins — the set of stops inside your walk radius stays fixed. For 8 stops or fewer the route is checked against every possible order and the shortest one wins; past that it's optimized with repeated local improvements, since checking every order gets too slow. Distances are still straight-line between event centers, not actual sidewalk distance, so treat the mileage as a floor, not a promise. Tap any stop for its exact cross streets, hours, and host — hours are also shown on every map pin and dot. Source: nyc.gov/trickorstreets.
